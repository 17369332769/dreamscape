# 无限梦境 · 产品设计文档

> AI 驱动的角色扮演互动小说游戏
> 版本：v1.3 · 完善稿

---

## 一、产品定位

### 核心体验

玩家化身任意角色，在 AI 构建的动态世界里做选择、说台词、改变命运。每一局都是独一无二的故事。

### 产品方向

- **类型**：角色扮演互动小说（玩家深度扮演主角）
- **目标用户**：泛用户（多类型覆盖）
- **商业模式**：免费 + 道具内购（梦境石体系）
- **上架平台**：微信小程序、QQ 小程序、抖音小程序

---

## 二、核心玩法

### 基本循环

```
选择/创建角色身份
       ↓
AI 生成开场场景（世界观 + 第一个冲突）
       ↓
玩家行动（选项 or 自由输入）
       ↓
AI 生成反应 + 推进剧情
       ↓
关键节点 → 存档 / 分叉 / 结局
```

### 互动方式（双轨制）

- **快速选项**：每段叙述后给 3 个预设行动，降低门槛，适合碎片化场景
- **自由输入**：玩家可以自己打"我做了 XXX"，AI 接受并响应
- 新手引导用选项，老玩家用自由输入

| 世界观 | 核心吸引力 | 主要人群 |
|--------|-----------|---------|
| 古风仙侠 | 修炼、门派、情缘 | 女性用户 |

| 星际文明 | 科幻、探索、政治 | 男性用户 |
| 恋爱养成 | 情感互动、多线攻略 | 女性用户 |
| 玩家自定义 | 输入任意设定 | 核心玩家 |

## 四、角色系统

### 设计原则

- **混合型属性**：少量核心数值 + 特质标签
- **跨世界观通用**：一套属性适配所有世界观，由 AI Prompt 负责语境映射
- **初始创建方式**：玩家自由分配属性点

### 核心属性（5项）

初始总点数：**10 点**，每项最低 1，最高 8

| 属性 | 在故事中的作用 |
|------|--------------|
| 武力 | 战斗、体力类选项的成功率 |
| 智谋 | 解谜、谋略类选项的成功率 |
| 魅力 | 说服、情感类选项的成功率 |
| 气运 | 随机事件的触发概率和走向 |
| 意志 | 抵抗诱惑、坚持极端选择的能力 |

### 特质标签（3类）

| 类型 | 上限 | 作用 |
|------|------|------|
| 性格特质 | 2个 | 影响 AI 叙事口吻和 NPC 对玩家的态度 |
| 能力特质 | 1个 | 解锁特殊行动选项 |
| 命运烙印 | 1个 | 在关键节点触发隐藏剧情分支 |

**性格特质示例**：孤傲冷峻、侠义热血、腹黑多谋、温柔善良、狂放不羁、谨慎多疑

**能力特质示例**：天生异禀、过目不忘、百毒不侵、鬼手医术、御兽之能、音律通神

**命运烙印示例**：天命之子、破而后立、因果纠缠、乱世浮萍、逆天改命、孤星煞命

### 角色创建流程（四步）

1. **基本信息**：名字、性别、背景描述
2. **属性分配**：自由分配 10 点属性
3. **特质选择**：选择性格/能力/命运标签
4. **预览确认**：查看角色卡片，进入梦境

## 五、道具与物品系统

### 设计原则

- **通用底层 + 世界观皮肤**：每件道具有抽象的底层类型，进入不同世界观后由 AI 渲染成对应名称和外观
- **双来源**：剧情中自然获得 + 商店购买
- **双作用**：影响剧情走向（解锁选项）+ 强化角色属性（数值加成）

### 道具分类体系

| 底层类型 | 仙侠皮肤 | 末世皮肤 | 都市异能皮肤 | 核心效果 |
|---------|---------|---------|------------|---------|
| 力量药剂 | 筑基丹 | 基因强化液 | 能量饮品 | 武力 +N，持续 1 章 |
| 智慧药剂 | 醒神香 | 神经增强剂 | 记忆胶囊 | 智谋 +N，持续 1 章 |
| 魅力道具 | 媚骨香 | 形象改造包 | 社交芯片 | 魅力 +N，持续 1 章 |
| 气运符文 | 转运符 | 幸运芯片 | 幸运护身符 | 气运 +N，持续 1 章 |
| 意志结晶 | 定心珠 | 意志强化剂 | 心理锚点 | 意志 +N，持续 1 章 |
| 钥匙道具 | 令牌/地图 | 通行证/情报 | 身份卡/线索 | 解锁特定剧情分支 |
| 关系道具 | 信物/礼物 | 物资/徽章 | 礼品/名片 | 提升特定 NPC 好感 |
| 消耗秘籍 | 功法残页 | 作战手册 | 技能手册 | 永久 +1 某属性（稀有）|

### 稀有度等级

| 等级 | 颜色 | 获取方式 | 属性加成 |
|------|------|---------|---------|
| 普通 | 灰 | 剧情常见奖励、商店低价 | +1 |
| 精良 | 绿 | 支线任务、商店中价 | +2 |
| 稀有 | 蓝 | 关键剧情奖励、限时活动 | +3，附带剧情解锁 |
| 史诗 | 紫 | 隐藏结局触发、高价购买 | +4，专属叙事描写 |
| 传说 | 金 | 极稀有随机掉落、赛季限定 | 永久属性提升 or 改变世界观规则 |

### 背包系统

- 初始 12 格，可购买扩展至 24 格
- 普通道具最多叠加 99 个，稀有及以上占独立格子
- 道具跨章节持续保留，切换世界观时自动切换皮肤展示

## 六、AI Prompt 系统设计

### Prompt 整体结构

```
System Prompt（每次都带）
├── 世界观规则书 Lorebook
├── 角色信息（属性 + 特质 + 道具加成）
└── 叙事风格指令

长期记忆摘要（压缩后的历史关键事件）

短期记忆（最近 5-7 轮对话）

当前用户行动
```

### 第一层：System Prompt 模板

```
你是一个沉浸式武侠小说的叙事引擎。

【世界观规则】
- 修仙世界，分练气、筑基、金丹、元婴四个境界
- 存在门派之争、魔道入侵两条主线冲突
- 禁止出现现代科技和现代词汇
- 死亡不是结局，失败触发"落难"状态继续剧情

【当前角色】
姓名：{name} / 性别：{gender} / 背景：{bio}
武力：{str} 智谋：{int} 魅力：{cha} 气运：{lck} 意志：{wil}
特质：{traits}
持有道具：{items}
当前道具加成：{active_buffs}

【叙事规则】
1. 每次回复 150-200 字，节奏明快
2. 结尾给出 3 个行动选项 [A] [B] [C]
3. 每隔 5 回合触发一次冲突或转折
4. 属性检定时在末尾输出 JSON：
   {"check": true, "type": "武力", "threshold": 6, "scene_tag": "战斗"}
5. 场景切换时输出：
   {"scene_tag": "城镇市集", "mood": "紧张"}
6. 语言风格：文言半白话，富有画面感
```

### 第二层：属性检定机制

```
玩家选择行动
     ↓
Claude 生成叙事 + 检定 JSON
{"check": true, "type": "智谋", "threshold": 5}
     ↓
后端计算：智谋(4) + 道具加成(+2) = 6 ≥ 阈值(5) → 成功
     ↓
注入结果：「检定结果：成功（智谋 6 ≥ 5），请叙事成功分支」
     ↓
Claude 生成对应叙事
```

### 第三层：记忆压缩策略

每满 10 轮触发一次，用独立 Claude 调用做摘要，压缩结果存入 MemFire Cloud：

```json
{
  "chapter": 1,
  "key_events": [
    "在落霞镇救了铁匠老陈，获得「玄铁令」",
    "与黑风寨寨主有过节，对方记恨在心"
  ],
  "npc_relations": {
    "老陈": {"好感": 8, "身份": "铁匠，知晓秘道"},
    "黑风寨主": {"好感": -5, "身份": "敌对势力"}
  },
  "active_quests": ["寻找秘道入口", "调查镇守使失踪案"]
}
```

### 第四层：输出格式控制

```json
{
  "narrative": "夜风卷过青石板路，你悄然潜入府邸侧门...",
  "options": [
    {"id": "A", "text": "顺着秘道深入"},
    {"id": "B", "text": "先观察四周动静"},
    {"id": "C", "text": "返回找老陈问清楚"}
  ],
  "scene_tag": "夜晚室内",
  "mood": "紧张",
  "check": null,
  "special_event": null
}
```

### Token 成本估算

| 部分 | 约 Token 数 |
|------|------------|
| System Prompt | ~500 |
| 长期记忆摘要 | ~200 |
| 短期记忆（5轮） | ~800 |
| 用户输入 | ~50 |
| AI 回复 | ~300 |
| **单次合计** | **~1850** |

Claude Sonnet 4 约 $3/百万 token，单次调用约 $0.005，完整一章（约 20 轮）成本约 **¥0.7**。

### 世界规则锚定

- 每个世界观预设专属 Lorebook，AI 生成内容限制在规则内
- 跨世界观属性映射：武力 7 在仙侠 = 内力深厚，在末世 = 体能超群
- 叙事节奏：每 5-7 回合触发冲突或转折，关键节点触发「史诗时刻」

## 八、NPC 系统

### NPC 分级

| 级别 | 类型 | 特点 | 例子 |
|------|------|------|------|
| 核心 NPC | 剧情绑定，反复出现 | 固定人设、完整记忆、好感度系统 | 师父、主要反派、爱情线角色 |
| 功能 NPC | 特定场景出现 | 有名字和职业，简单好感度 | 客栈老板、铁匠、商人 |
| 路人 NPC | 一次性 | AI 随机生成，不存储 | 街头百姓、小喽啰 |

### 好感度区间

| 好感度 | 状态 | NPC 行为变化 |
|--------|------|------------|
| 0-20 | 陌生/警惕 | 对话简短，不主动提供信息 |
| 21-40 | 普通 | 正常互动，偶尔提供线索 |
| 41-60 | 友好 | 主动帮助，提供隐藏选项 |
| 61-80 | 信任 | 透露秘密，关键时刻相助 |
| 81-100 | 深厚羁绊 | 触发专属剧情线，改变故事走向 |

### NPC 记忆注入 Prompt

```
【当前互动 NPC：剑无痕】
性格：严厉冷峻，内心慈悲
当前好感度：45（友好）
他记得：玩家在试炼中选择救人而非夺宝 / 玩家曾质疑过他的决定
可触发事件：传功事件（好感 ≥ 50 解锁）
注意：他知道玩家的真实身份，但还不会说出来
```

### 好感度变化机制

AI 回复末尾附加好感度变化 JSON，后端写入数据库：

```json
{
  "affection_change": {
    "npc_id": "npc_shifu_001",
    "delta": +5,
    "reason": "玩家选择了尊重师父的决定"
  }
}
```

### 与其他系统的联动

- **道具系统**：`relation_items` 让关系道具与 NPC 直接挂钩
- **AI Prompt**：NPC 记忆和好感度注入 System Prompt，不会前后矛盾
- **存档系统**：`npc_relations` 存在 saves 表，换存档关系重置，支持多周目
- **商业化**：高好感专属剧情作为付费点——「解锁 NPC 真实故事线」

## 九、章节结构设计

### 章节基本参数

| 参数 | 设定 |
|------|------|
| 每章回合数 | 15-25 轮 |
| 每章字数 | 约 3000-4500 字 |
| 关键选择数 | 每章 3-5 个 |
| 结局数量 | 每章 2-4 个 |

### 章节内部节奏：五段式结构

```
第一段：引入（回合 1-3）    平静开场，交代场景
      第二段：触发（4-6）   第一个冲突，第一个关键选择 ★
            第三段：发展（7-14）  属性检定集中，NPC 关系变化
      第四段：高潮（15-20） 最大冲突，史诗时刻 ✦，最重要选择 ★★
第五段：结局（21-25）       2-4 种不同结局，留下钩子
```

### 结局判定逻辑

```
章节结束 → 后端统计关键选择 + NPC 好感度 + 持有道具 → 匹配结局条件 → 传给 AI 生成收尾叙事
```

### 章节间钩子

```json
{
  "chapter_end": true,
  "ending_type": "A",
  "hook": "就在你以为一切尘埃落定时，师父望向远山，缓缓说出了一个你从未听过的名字……",
  "next_chapter_hint": "下一章：真相"
}
```

### 多章节整体弧线

| 章节 | 内容 | 商业化 |
|------|------|--------|
| 序章 | 世界观介绍，角色初登场 | 完全免费 |
| 第一章 | 第一个冲突，建立人物关系 | 免费 |
| 第二章起 | 剧情深入，秘密开始揭露 | 消耗梦境石 |
| 隐藏章节 | 特定条件触发的支线 | 高价值付费 |
| 终章 | 大结局，多结局收尾 | 消耗梦境石 |

## 十、用户成长体系

### 两条成长线

```
角色成长线（单个角色的纵向积累）＋ 玩家账号成长线（跨角色的横向积累）
```

### 角色成长

| 触发条件 | 效果 |
|---------|------|
| 同类属性检定成功 3 次 | 该属性 +1 |
| 使用消耗秘籍道具 | 对应属性 +1 |
| 完成特定章节结局 | 属性上限从 8 提升至 12 |
| 命运烙印触发后 | 烙印对应属性永久 +2 |

境界系统：练气期 → 筑基期 → 金丹期 → 元婴期（跨世界观有不同皮肤）

### 玩家账号等级

| 等级 | 名称 | 解锁内容 |
|------|------|---------|
| 1-5 | 入梦者 | 基础功能 |
| 6-15 | 寻梦者 | 解锁自定义世界观 |
| 16-30 | 织梦者 | 创作者工具，可发布故事 |
| 31-50 | 筑梦者 | 专属称号，社区高权重 |
| 51+ | 造梦神 | 限定内容，官方合作资格 |

### 成就系统

触发方式：显性成就（进度条可见）+ 隐性成就（做了才弹出，带惊喜感）

成就分五级：普通（灰）/ 精良（绿）/ 稀有（蓝）/ 史诗（紫）/ 传说（金）

成就示例：

| 成就名 | 触发条件 | 等级 |
|--------|---------|------|
| 初入江湖 | 完成第一章 | 普通 |
| 以柔克刚 | 武力最低却通关一章 | 稀有 |
| 八面玲珑 | 同一章让所有 NPC 好感 +10 | 稀有 |
| 天命归一 | 解锁全部 4 种章节结局 | 史诗 |
| 千古绝唱 | 故事被收藏超过 1000 次 | 传说 |

成就弹出时机：章节结局页或等待 AI 回复时，不在剧情高潮打断沉浸感。

### 收集图鉴

分五类，未解锁显示"???"制造收集欲：

- **场景图鉴**：到达过的场景自动解锁
- **NPC 图鉴**：好感度 ≥ 60 解锁隐藏背景故事，驱动玩家刷好感
- **道具图鉴**：未获得道具提示"可在 XX 场景获得"
- **结局图鉴**：直接推动二周目
- **故事图鉴**：每局自动生成故事卡，可一键分享朋友圈

### 成就与图鉴联动

```
解锁图鉴条目 → 触发收集类成就
完成成就 → 奖励特殊道具 → 道具进图鉴
图鉴完成度 XX% → 触发隐性成就「博览群书」
所有结局解锁 → 触发史诗成就「天命归一」
```

### 每日任务

| 任务 | 奖励 |
|------|------|
| 完成 1 个回合 | 梦境石 ×3 |
| 触发 1 次属性检定 | 故事金币 ×10 |
| 与任意 NPC 互动 | 故事金币 ×15 |
| 完成 1 个章节 | 梦境石 ×10 + 随机道具 |
| 连续 7 天登录 | 限定称号 or 稀有道具 |

### 赛季体系

每 2-3 个月一个赛季，带来新世界观/章节、限时道具和称号、排行榜，结束时发放纪念徽章。

## 十一、难度平衡：属性检定阈值设计

### 动态阈值

```
阈值 = 基础难度 × 章节系数 × 随机浮动(±1)
```

始终保持"有点悬但能过"的紧张感。

### 三段式成功率区间

| 区间 | 成功率 | 玩家感受 |
|------|--------|---------|
| 舒适区（属性远超阈值） | 85-95% | 强大感，偶尔意外失败 |
| 挑战区（属性接近阈值） | 50-70% | 紧张但有希望，最有趣 |
| 困难区（属性低于阈值） | 15-30% | 需要道具辅助或换策略 |

永远不出现 100% 或 0%。

### 属性堆满的四个专项对策

**① 多属性联合检定**

```
普通场景：武力 ≥ 6（单属性）
困难场景：武力 + 意志 ≥ 12（双属性）
极限场景：武力 + 智谋 + 气运 ≥ 16（三属性）
```

**② 属性克制关系**

| 场景 | 克制效果 |
|------|---------|
| 魔道场景 | 武力检定 -2 |
| 社交场合 | 武力检定 -3 |
| 幽暗秘境 | 魅力检定 -2 |

**③ 状态系统**

| 状态 | 来源 | 效果 |
|------|------|------|
| 中毒 | 特定场景 | 武力 -2，持续 1 章 |
| 心乱 | 负面选择 | 智谋 -2，下回合 |
| 受伤 | 战斗大幅失败 | 武力 -3，需道具治疗 |

**④ 道具加成上限**：同类道具同章只生效 1 个，单属性加成上限 +4。

### AI 侧配合

```json
{
  "difficulty_hint": {
    "suggested_checks": ["int", "cha"],
    "avoid_checks": ["str"],
    "chapter_difficulty": "hard"
  }
}
```

## 十四、游戏主界面和章节流程 UI 设计

### MVP 页面结构

第一版不做复杂大厅，主界面围绕「继续梦境」展开，降低用户进入剧情的步骤。

| 页面 | 核心功能 | MVP 优先级 |
|------|---------|-----------|
| 首页 | 继续梦境、创建角色、背包、图鉴入口 | P0 |
| 世界选择页 | 选择世界观，MVP 仅开放古风仙侠 | P0 |
| 角色创建页 | 基本信息、属性分配、特质选择、角色确认 | P0 |
| 剧情主界面 | 场景图、正文、选项、角色状态、背包快捷入口 | P0 |
| 章节结算页 | 结局、关键选择、奖励、NPC 好感变化、下一章入口 | P0 |
| 付费/消耗弹窗 | 第二章起消耗梦境石，展示余额与消耗原因 | P1 |
| 图鉴页 | 场景、NPC、道具、结局收集 | P2 |
| 社区广场 | 围观他人故事、点赞、收藏 | P3 |

### 剧情主界面布局

竖屏优先，底部操作区放在拇指热区，减少阅读和选择之间的跳转。

```text
┌────────────────────────┐
│ 场景图 / 角色立绘       │
├────────────────────────┤
│ 第一章 · 落霞镇疑云     │
│ 回合 7 / 20             │
├────────────────────────┤
│ AI 叙事正文             │
│ 重要台词高亮显示        │
│ 属性检定结果轻提示      │
├────────────────────────┤
│ [A] 直接追上黑衣人      │
│ [B] 先询问铁匠老陈      │
│ [C] 使用玄铁令查看密道  │
├────────────────────────┤
│ 角色  背包  存档        │
└────────────────────────┘
```

### 章节流程

```text
首页
 ↓
选择/继续存档
 ↓
角色创建或确认
 ↓
章节开场
 ↓
剧情回合循环：叙事 → 选项 → 检定 → 结果
 ↓
关键选择记录
 ↓
章节高潮
 ↓
结局判定
 ↓
章节结算页
 ↓
下一章 / 重玩 / 分享故事卡
```

### 交互原则

- **选项优先**：MVP 暂不开放自由输入，降低内容安全和剧情失控风险。
- **状态轻提示**：属性变化、好感变化、道具获得用轻量浮层展示，不打断剧情。
- **付费不强拦高潮**：付费点放在章节入口、番外、隐藏线，不在关键结局前突然截断。
- **失败可继续**：检定失败进入「落难」「受伤」「错失线索」等状态，不直接 Game Over。
- **每章可回顾**：结算页展示关键选择，帮助玩家理解自己如何走到当前结局。

## 十五、背包 UI 和道具使用交互设计

### 背包定位

背包不是传统 RPG 的复杂仓库，而是剧情辅助工具。核心目标是让玩家在关键节点感到「我之前获得的东西真的有用」。

### 道具使用方式

| 使用方式 | 触发场景 | 示例 |
|---------|---------|------|
| 主动使用 | 玩家打开背包选择道具 | 使用「定心珠」解除心乱状态 |
| 剧情触发 | 某个选项需要道具 | 出示「玄铁令」进入密道 |
| 自动提示 | 系统发现道具可影响检定 | 是否使用「醒神香」让智谋 +2 |
| 结算消耗 | 章节结束后自动发放或扣除 | 使用一次性钥匙道具开启隐藏结局 |

### 剧情选项中的道具表达

```text
[A] 正面闯入镇守府
[B] 绕到后院寻找破绽
[C] 出示玄铁令进入秘道    道具解锁
```

### 背包详情信息

每个道具展示以下字段：

- 道具名称
- 稀有度
- 当前世界观描述
- 实际效果
- 持续时间
- 获取来源
- 是否本章可用
- 使用按钮

### MVP 道具范围

第一版只保留 4 类道具，避免经济系统过早复杂化。

| 类型 | 作用 | 示例 |
|------|------|------|
| 属性临时加成 | 提升一次或一章检定能力 | 筑基丹、醒神香 |
| 剧情钥匙 | 解锁隐藏选项或结局 | 玄铁令、残破地图 |
| NPC 关系道具 | 提升特定 NPC 好感 | 玉佩、信物 |
| 章节奖励 | 结算时获得，影响后续章节 | 门派令、秘术残页 |

### 暂缓内容

- 背包格子扩展
- 复杂叠加规则
- 多世界观自动换皮
- 大型商店
- 传说级规则改写道具

这些内容保留在二期，等验证留存和付费后再扩展。

## 十八、内容审核方案

### 审核目标

内容审核要同时覆盖玩家输入、AI 输出、图片生成和分享传播，防止违规内容进入用户可见界面。

### 审核链路

```text
用户输入
 ↓
输入审核
 ↓
AI 生成
 ↓
输出审核
 ↓
结构化解析与入库
 ↓
展示给用户
 ↓
分享/发布前二次审核
```

### 审核对象

| 对象 | 风险 | MVP 策略 |
|------|------|---------|
| 角色名 | 低俗、政治、冒充名人 | 创建前审核 |
| 背景描述 | 色情、暴力、违法、敏感内容 | 创建前审核 |
| 自由输入 | 注入攻击、违规剧情诱导 | MVP 暂不开放 |
| AI 剧情正文 | 违规内容、过度暴力、擦边、敏感议题 | 展示前审核 |
| AI 选项 | 引导违法、危险行为、极端选择 | 展示前审核 |
| 图片 Prompt | 色情、未成年人、敏感人物 | 生成前审核 |
| 分享卡 | 公开传播风险 | 发布前二次审核 |
| 社区评论 | UGC 风险 | 二期再开放 |

### 审核策略

- **MVP 暂不做自由输入**：所有玩家行动来自预设选项，显著降低风险。
- **先审后显**：AI 回复完整生成后先过审核，再模拟打字机展示。
- **结构化输出校验**：AI 返回必须符合 JSON Schema，解析失败则重试或走兜底文案。
- **敏感命中降级**：违规内容不展示，改用安全兜底剧情推进。
- **人工复核入口**：用户可举报剧情、图片和分享卡。
- **审核日志留存**：记录输入、输出、命中规则、处理结果，便于追溯。

### 兜底文案示例

```json
{
  "narrative": "雾气忽然漫过长街，你意识到眼前的线索并不完整。短暂迟疑后，你决定换一种方式继续调查。",
  "options": [
    {"id": "A", "text": "返回客栈整理线索"},
    {"id": "B", "text": "寻找老陈询问往事"},
    {"id": "C", "text": "前往镇口查看异动"}
  ],
  "scene_tag": "城镇街道",
  "mood": "悬疑",
  "check": null,
  "special_event": "safe_fallback"
}
```

### 合规重点

- AI 生成内容需有明确管理机制和必要标识。
- 面向未成年人时，需特别控制沉迷、诱导消费、情感依赖和不适龄内容。
- 用户数据、聊天内容、生成内容和支付信息需按国内合规要求存储和处理。
- 若开放社区和分享，需要建立公开内容审核、举报、下架和申诉流程。

## 二十一、图片与沉浸感系统

### 三层图片体系

```
第一层：预生成图库（约 80% 使用量）
   ↓ 匹配度低时
第二层：AI 实时生成（约 15% 使用量）
   ↓ 生成后缓存
第三层：缓存复用池
```

### 角色立绘生成

角色创建时一次性生成，永久绑定，Prompt 自动组装规则：

| 维度 | 转化逻辑 |
|------|---------|
| 世界观 | 古风仙侠 → 国风水墨插画风格 |
| 特质标签 | 孤傲冷峻 → 眉眼清冷，白衣飘逸 |
| 最高属性 | 智谋最高 → 手持书卷，智慧气质 |

首次生成免费，重新生成消耗梦境石。

### 沉浸感增强

- **文字层**：关键词高亮、打字机效果、重要台词居中展示
- **音效层**：环境音按场景标签切换，使用 Freesound 免版权音效
- **动效层**：场景切换渐入渐出、史诗时刻粒子特效
